NAME

       betterecho - display line(s) of stylized text

SYNOPSIS

       betterecho [STRING] ...
       betterecho [OPTION] [STRING] ...

DESCRIPTION

       Echo the STRING(s) to standard output, with styling and colors if specified.

       -b
            print string in bold

       -u
            print string underlined

       -c R G B
            print string with colors specified by their red, green and blue values,
            ranging from 0 to 255.
